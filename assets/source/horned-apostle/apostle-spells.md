# Apostle void spell kit

`apostle-spells.blend` is the editable, labeled Blender inspection layout. All eleven motifs are generated by `scripts/build-apostle-spells.py`; each root's local geometry uses metres, Y-up and +Z front in the exported GLB. The builder exports the identity gameplay roots before arranging the Blender inspection scene. The camera, labels and lights are never shipped.

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --threads 4 --disable-autoexec --python scripts/build-apostle-spells.py -- --render
node scripts/check-apostle-spell-assets.mjs
```

The kit uses two shared vertex-color materials: carved obsidian and luminous void inlays. Violet, cyan and lilac carry the light; there are no warm gold surfaces, textures or decoder downloads. Each root contains two direct mesh children, except the star's three independent `core`, `shards` and `runes` meshes. Clone or instance these buffers; animate and fade with the raid's authoritative timestamps. Mesh detail does not define damage bounds.

The vortex ribbons extend slightly below the base pivot; raise by 0.12 m when seating them on a floor. `apostle-spells-preview.png` renders these authored meshes in Blender; smaller motifs are enlarged there for inspection.
