# Mossvale

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Mossvale is a browser fantasy MMORPG. The wiki at wiki.mossvale.world explains monsters, dungeons, leveling, and the surrounding game systems.

## Capabilities and Constraints

The existing game uses TypeScript, Vite, and Three.js. Wiki facts come from the checked-in game catalogs and server behavior. The wiki has its own static deployment so publishing guides does not restart the game.

## Brand Commitments

Preserve the Mossvale name, existing woodland fantasy artwork, and readable game terminology.

## Evidence on Hand

Game data in src/, server rules in server.mjs, and authored artwork in public/ui/. Current user request establishes the wiki domain and its core subjects.
